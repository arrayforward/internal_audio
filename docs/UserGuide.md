# 内部录音机 —— 详细使用说明书

> 适用版本：v1.0.0 ｜ 适用系统：Android 10 及以上（含 HarmonyOS）
> 本文档手把手教你完成从安装到录音、播放、剪辑的全部操作。

---

## 一、安装应用

1. 打开 GitHub 发布页：<https://github.com/arrayforward/internal_audio/releases/latest>
2. 在 **Assets** 中点击下载 `internal_audio-v1.0-debug.apk`。
3. 下载完成后点击 APK 文件安装。
   - 若系统提示“禁止安装未知来源应用”，请按提示前往 **设置 → 安全 → 安装未知应用**，允许浏览器/文件管理器安装。
   - 华为手机可能提示“未经华为应用市场安全检测”，选择 **继续安装** 即可。
4. 安装完成，桌面出现「内部录音机」图标（紫色音符图标）。

---

## 二、首次启动与授权（重要，只需一次）

首次打开应用，系统会依次请求以下权限，请**全部允许**：

### 2.1 麦克风权限
- 弹窗“是否允许 内部录音机 录制音频？”→ 选择 **使用应用时允许**。
- 说明：这是 Android 系统的强制要求（内部录音也被归类为录音行为），应用**不会**采集麦克风声音。

### 2.2 通知权限（Android 13+）
- 弹窗“是否允许发送通知？”→ 选择 **允许**。
- 用途：录音时在通知栏显示“正在录制”状态，防止系统误杀后台服务。

### 2.3 所有文件访问权限（Android 11 及以上 / HarmonyOS）
1. 点击主界面的 **● 录音** 按钮时，应用会弹窗提示“需要文件访问权限”。
2. 点击 **去开启**，跳转到系统设置页。
3. 在设置页中找到「内部录音机」，打开 **允许访问所有文件** 开关。
4. 按返回键回到应用。
- 用途：把录音文件保存到公共目录 `/sdcard/Music/audio/`，方便你用文件管理器查看。
- Android 10 设备无此步骤，改为授权“存储权限”即可。

> ✅ 授权完成后，以后使用无需再次授权。

---

## 三、开始录音（一步一步）

1. 打开「内部录音机」。
2. **选择输出格式**：点击“输出格式”下拉框：
   - **WAV**：无损音质，文件较大（约 20MB/分钟），适合后期剪辑。
   - **M4A**：AAC 192kbps，音质高、文件小（约 1.4MB/分钟），适合日常保存。
   - **MP3**：当前版本未集成 LAME 编码库，选择后会自动降级为 M4A 保存。
3. 先让手机开始播放你想录制的声音（如音乐 App、视频、游戏音效）。
4. 回到「内部录音机」，点击红色 **● 录音** 按钮。
5. 系统弹出**录屏授权窗口**（“内部录音机将开始截取您屏幕上显示的所有内容”）→ 点击 **立即开始/允许**。
   - 这是 Android 平台的强制要求，应用只取声音、不录制画面。
6. 开始录制后：
   - 按钮变为 **⏹ 停止**；
   - 波形区实时跳动容量的柱状图；
   - 计时器从 `00:00:00` 开始走动；
   - 通知栏显示“正在录制内部音频”。
7. 录制过程中可以切出去操作其他 App，录音在后台继续。

> ⚠️ 注意：部分 App（如某些银行、版权音乐 App）声明了禁止被捕获，录制这些 App 时文件会是静音，这是系统限制，属正常现象。

---

## 四、停止录音与自动保存

1. 回到「内部录音机」（可从通知栏点击通知直接返回）。
2. 点击 **⏹ 停止** 按钮。
3. 应用自动生成随机文件名并保存，例如 `recording_kpnxt7.wav`。
4. 屏幕下方弹出提示“已保存: /sdcard/Music/audio/recording_kpnxt7.wav”。
5. 文件立即出现在下方「录音列表」的第一条（最新在最上面）。

保存规则：
- 目录：`内部存储/Music/audio/`（可用文件管理器进入 **音乐/audio** 文件夹查看）
- 命名：`recording_` + 6 位随机小写字母数字 + 格式扩展名

---

## 五、播放录音（应用内播放器）

1. 在录音列表中找到目标文件，点击右侧 **▶️ 播放图标**。
2. 进入应用内播放页：
   - 顶部显示文件名；
   - 中间显示**完整音频波形示意图**；
   - 波形下方左侧为当前播放时间，右侧为总时长。
3. 点击底部圆形 **▶️ 按钮** 开始播放，按钮变为 **⏸ 暂停**。
4. 播放时波形上有**蓝色竖线**实时跟随播放位置移动。
5. **快进/快退**：直接**点按波形上的任意位置**，即从该位置开始播放。
6. 播放完毕后进度自动归零；点击左上角 **✕** 返回列表。

---

## 六、剪辑录音（去掉头尾多余片段）

1. 在录音列表中点击目标文件的 **✂️ 剪刀图标**，进入剪辑页。
2. 等待波形加载完成（大文件需要 1~2 秒）。
3. 顶部信息栏显示：**原始时长 ｜ 选中时长 ｜ 格式**。
4. **调整保留范围**（两种方式，效果相同）：
   - 方式一：直接**拖动波形两端的红色手柄**——左手柄控制起点，右手柄控制终点。灰色区域将被裁掉，高亮区域将被保留。
   - 方式二：拖动波形下方的**双滑块条**，可进行更精细的毫秒级微调。
5. **试听确认**：点击 **🔊 试听选区**，只播放高亮部分；也可点 **▶️** 随时暂停。
6. **不满意可重来**：点击 **🔄 重置选区** 恢复整段全选。
7. 确认无误后，选择保存方式（页面右上角）：
   - **保存为副本**（推荐）：原文件保留，生成新文件，如 `trimmed_recording_kpnxt7_x3k9p2.wav`。
   - **覆盖保存**：弹出确认框 → 点击 **覆盖**，原文件被裁剪后的内容替换（不可恢复，谨慎使用）。
8. 保存成功弹出提示，自动返回列表并刷新。

> ⚠️ 限制：保留时长最短 1 秒；MP3 文件的剪辑需要 LAME 库，当前版本会提示不支持。

---

## 七、重命名录音

1. 点击列表项的 **✏️ 铅笔图标**。
2. 弹出对话框，输入框中显示当前文件名（不含扩展名）。
3. 输入新名字（不能包含 `\ / : * ? " < > |` 等特殊字符）。
4. 点击 **确定**，列表立即刷新。
- 扩展名（.wav / .m4a）由系统锁定，不可修改。

---

## 八、删除录音

1. 点击列表项的 **🗑️ 垃圾桶图标**。
2. 弹出确认框“确定删除 xxx 吗？”。
3. 点击 **删除**，文件从 `/sdcard/Music/audio/` 中移除，列表刷新。
- 删除不可恢复，请谨慎操作。

---

## 九、常见问题（FAQ）

| 问题 | 解决办法 |
|------|----------|
| 点击录音没反应 | 检查是否授予了麦克风权限（设置 → 应用 → 内部录音机 → 权限） |
| 提示“需要文件访问权限” | 按提示去系统设置开启“所有文件访问”后重试 |
| 提示“系统授权失败” | 录屏授权窗口点了取消，重新点击录音并选择“立即开始” |
| 录出来的文件没有声音 | 目标 App 禁止被捕获（系统限制），换其他音源试试；或确认播放时媒体音量不为 0 |
| 录音中手机来电话/被打断 | 系统会回收录屏授权，录音自动停止并保存已录片段 |
| 文件管理器里找不到文件 | 进入 **内部存储 → Music → audio** 文件夹；部分管理器需刷新 |
| WAV 文件很大 | 正常现象（无损约 20MB/分钟），日常使用建议选 M4A |

---

## 十、隐私说明

- 本应用**不联网**、不收集任何数据；
- 所有录音文件仅保存在本机 `/sdcard/Music/audio/`；
- 录屏授权仅用于获取音频流，不会截取或保存任何屏幕画面。
